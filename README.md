## Featured Projects

### Brain Tumor MRI Classification

Binary brain MRI classification project built with TensorFlow/Keras. The repository includes preprocessing, CNN training, evaluation metrics, prediction scripts, and a Gradio demo.

[View project](https://github.com/adi-gp/brain-tumor-mri-classification)

### Mosquito Species Classification

Bioacoustics deep learning pipeline for mosquito species identification from raw `.wav` audio. Uses a dual-branch approach with log-mel spectrogram CNN + Bi-GRU attention and pretrained audio embeddings.

### AI-Powered Event Scheduler

Workflow automation project using n8n, VAPI, Python, and REST APIs to create and confirm events through voice-based interaction.

### Telegram-to-Twitter Auto-Poster Bot

Python bot that listens to Telegram messages and publishes them to Twitter/X with authentication, media handling, and retry logic.
